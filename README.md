# Modern Villa Visualization

## 📌 Overview

This project showcases a modern villa design with a focus on clean geometry, natural lighting, and spatial clarity.
The goal is to create a visual experience that helps clients understand the space before construction.

---

## 🧠 Design Approach

* Minimal yet expressive architectural language
* Strong connection between interior and exterior
* Emphasis on light, shadow, and material realism

---

## 🛠️ Tools Used

* 3ds Max
* Corona Renderer
* Photoshop
